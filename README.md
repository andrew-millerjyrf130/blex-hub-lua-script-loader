## About Blex Hub

Blex Hub provides a Windows-based way to browse, organize, and launch Roblox game scripts. Its design emphasizes executor compatibility and Lua-style execution, while the compact desktop layout keeps script categories easy to find without adding unnecessary interface clutter.

The hub is aimed at common Roblox searches involving scripts, executors, Steal a Brainrot, desync, duel, and semi TP. Its organization gives particular attention to duel scripts, semi TP choices, and desync-related entries for users seeking a lightweight script hub with straightforward navigation.
